# 指示書：子牛売買申込み（オスメス両対応・ドナドナ演出）実装

## これは何の作業か

子牛（オスメス問わず）が生後17〜20日目の間、街の市場で売買申込みができるようにする。
申込んだ翌日の「1日の始まり」で、トラックが遠ざかっていく演出（ドナドナ）とともに
売値を表示する。以前の「オス限定・21日固定」設計は破棄し、今回の内容に統一する。

申込まずに20日目を過ぎて成牛になった場合の扱い（魔力・スキルなしの状態）は
今回のスコープ外。その牛自体の売却ルートも別途対応する。
成牛(すでに大人になった牛)の売却も今回はスコープ外。

---

## ①申込み対象の判定・通知（アップキープ）

- 各子牛について、**その子牛の生誕日からの経過日数**が17〜20日の間、売買申込み対象とする
  （ゲーム開始からの通算日数ではなく、子牛ごとの誕生日基準でカウントすること）
- 対象の子牛が1頭以上いる日は、「1日の始まり」で2行の通知を表示する
  - 1行目：対象の子牛がいることを伝える一言
  - 2行目：牛舎で確認するよう促す一言
- 複数頭が対象でも、通知は1回・2行にまとめる（頭数分の通知を出さない）
- 申込まないまま日が経っても、対象である間（17〜20日目）は毎日同じ通知が出る

---

## ②街の市場での申込み（street.js等）

- 牛舎または街の市場から、対象の子牛それぞれに「売買申込み」ができるようにする
- メスの子牛が申込まれた場合、そのメスは**母牛への昇格対象から外れる**（申込み＝繁殖ルートを選ばない意思表示として扱う）
- 申込むと、対象の子牛は「申込み済み」状態になる

---

## ③売値の計算式（common.js）

```js
// 基本額
const CALF_SALE_BASE_MALE = 400000;    // オス基本額
const CALF_SALE_BASE_FEMALE = 300000;  // メス基本額（オスより10万円安い）
const CALF_SALE_RATE = 4000;           // qualityPoint 1ptあたりの上乗せ額
const CALF_SALE_BONUS_MAX = 0.08;      // 上振れの最大率（0〜8%、下振れなし）

function calcCalfSalePrice(qualityPoint, sex) {
  const base = (sex === 'male' ? CALF_SALE_BASE_MALE : CALF_SALE_BASE_FEMALE)
    + qualityPoint * CALF_SALE_RATE;
  const bonusRate = Math.random() * CALF_SALE_BONUS_MAX; // 0〜0.08
  return Math.round(base * (1 + bonusRate));
}
```

- 下振れは無し。計算式通りの金額が最低保証で、そこから0〜8%上乗せされる
- 定数は後から調整しやすいよう、1箇所にまとめておく

---

## ④ドナドナ演出（申込み翌日のアップキープ、新規シーン）

- 申込み済みの子牛がいる場合、翌日の「1日の始まり」で専用の演出画面に遷移する
- 背景・トラックのスプライトは、今回Claude Codeが見えるフォルダに配置済みのものを使用する
- トラックが奥に向かって小さく・遠ざかっていくように見せる（クロスフェード、position/scaleのトランジション等、実装しやすい方法でよい）
- トラックが去った後、テキストで以下を表示する:
  - 「（子牛の名前）が、旅立っていった」のような一言
  - 「売値：◯◯円」（③の計算式で算出した金額）
- 複数頭が同時に申込み済みの場合は、1頭ずつ順番に演出→金額表示を繰り返す
- 表示後、閉じるボタン等で通常のアップキープフローに戻る

---

## 触らないこと

- 母牛の品質・妊娠・発情ロジック
- 申込まずに成牛になった牛の挙動（別指示書で対応）
- 既存の出産ロジック本体

---

## 完成の目安

1. 子牛が生後17日目になると、対象がいる旨の2行通知が「1日の始まり」で表示される
2. 街の市場（または牛舎）から申込みができ、メスの場合は母牛昇格対象から外れる
3. 申込んだ翌日、ドナドナ演出とともに売値が表示される（複数頭なら順番に）
4. 売値はqualityPoint・性別に応じて計算式通りに算出され、0〜8%の範囲でランダムに上乗せされる
5. 20日目を過ぎても申込まれなかった子牛は、今回のスコープ外の状態に移行する（今回はその移行トリガーの存在だけ用意されていればよく、詳細挙動は次回）
